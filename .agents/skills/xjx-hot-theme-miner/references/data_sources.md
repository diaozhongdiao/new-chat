# 数据源与 API 接口规范

## 概述

热门题材挖掘依赖东方财富（EastMoney）公开数据接口，覆盖概念板块行情、成分股明细、个股资金流向、基本面快照、涨停股列表、市场整体情绪六大数据维度。所有接口均为 HTTP GET 请求，返回 JSONP 格式数据。

---

## 1. 概念板块行情

### 用途

获取所有概念板块的实时行情数据，作为题材筛选的原始输入。

### 接口说明

- **来源**: 东方财富概念板块行情接口
- **请求方式**: HTTP GET
- **返回格式**: JSONP（需提取 JSON 部分解析）

### 关键返回字段

| 字段 | 含义 | 单位/说明 |
|:---|:---|:---|
| 板块代码 | 概念板块唯一标识 | 如 BK0XXX |
| 板块名称 | 概念板块中文名称 | |
| 涨跌幅 | 板块当日涨跌幅 | 百分比 |
| 领涨股名称 | 板块内涨幅最大的个股名称 | |
| 领涨股涨幅 | 领涨个股涨跌幅 | 百分比 |
| 总市值 | 板块总市值 | 元 |
| 换手率 | 板块整体换手率 | 小数（如 0.05 表示 5%） |
| 成交额 | 板块当日成交额 | 元 |
| 上涨家数 | 板块内上涨个股数量 | |
| 下跌家数 | 板块内下跌个股数量 | |

### 数据清洗规则

- 对返回数据按板块涨幅降序排列
- 板块涨幅、换手率等数值字段做类型转换，缺失值填 0
- 板块名称去除前后空格

## 2. 板块成分股

### 用途

获取指定概念板块内所有个股的实时行情，用于后续个股评分。

### 接口说明

- **来源**: 东方财富板块成分股接口
- **请求方式**: HTTP GET
- **参数**: 板块代码（如 BK0XXX）、分页参数
- **返回格式**: JSONP

### 关键返回字段

| 字段 | 含义 | 单位/说明 |
|:---|:---|:---|
| 股票代码 | 6位数字代码 | |
| 股票名称 | 个股中文简称 | |
| 最新价 | 当前交易价格 | 元 |
| 涨跌幅 | 当日涨跌幅 | 百分比 |
| 成交量 | 当日成交量 | 手 |
| 成交额 | 当日成交额 | 元 |
| 换手率 | 当日换手率 | 小数（0.05 = 5%） |
| 量比 | 量比指标 | |
| 总市值 | 总市值 | 元 |
| 流通市值 | 流通市值 | 元 |

### 数据清洗规则

- 成分股按涨跌幅降序排列
- 默认获取前 50 只成分股（可调整）
- 换手率从百分比转换为小数（除以 100）
- 缺失的数值字段填 0

## 3. 个股资金流向

### 用途

获取指定个股近 N 日的主力资金流向数据，判断资金趋势。

### 接口说明

- **来源**: 东方财富个股资金流接口
- **请求方式**: HTTP GET
- **参数**: 股票代码、市场标识（沪市1/深市0）、天数
- **返回格式**: JSONP

### 市场标识规则

- 股票代码以 `6` 开头 → 沪市（标识 1）
- 股票代码以 `0`、`3` 开头 → 深市（标识 0）

### 关键返回字段（每日）

| 字段 | 含义 | 单位/说明 |
|:---|:---|:---|
| 日期 | 交易日期 | |
| 主力净流入 | 当日主力净流入金额 | 万元 |
| 收盘价 | 当日收盘价 | 元 |

### 数据聚合规则

对近 N 日的数据进行聚合统计：

| 聚合指标 | 计算方式 | 说明 |
|:---|:---|:---|
| 累计主力净流入 | 各日主力净流入之和 | 万元 |
| 最近一日主力净流入 | 最近交易日的主力净流入 | 万元 |
| 正流入天数 | 主力净流入 > 0 的天数 | |
| 资金趋势 | 见下方判定规则 | |

### 资金趋势判定规则

| 条件 | 趋势标签 |
|:---|:---|
| 正流入天数 ≥ 总天数的 60% 且 累计净流入 > 0 | **持续流入** |
| 最近一日净流入 > 0 | **今日流入** |
| 其他情况 | **流出** |

### 异常处理

- 接口请求失败时返回默认值：趋势="未知"，所有金额=0
- 查询天数默认为 5 个交易日

## 4. 个股基本面

### 用途

获取指定个股的估值与财务数据快照，用于基本面评分和价格预测。

### 接口说明

- **来源**: 东方财富个股基本面数据接口
- **请求方式**: HTTP GET
- **参数**: 股票代码（带市场后缀，沪市 `.SH` / 深市 `.SZ`）
- **返回格式**: JSONP

### 关键返回字段

| 字段 | 含义 | 单位/说明 |
|:---|:---|:---|
| 股票名称 | 个股中文简称 | |
| 最新价 | 当前价格 | 元 |
| PE(TTM) | 滚动市盈率 | 倍 |
| PB | 市净率 | 倍 |
| 总市值 | 总市值 | 亿元（接口返回元，需换算） |
| 营收同比增速 | 最近报告期营收同比 | 百分比 |
| 净利润同比增速 | 最近报告期净利润同比 | 百分比 |
| ROE | 净资产收益率 | 百分比 |

### 数据清洗规则

- 总市值从元转换为亿元（÷ 1e8）
- 所有数值字段缺失时填 0
- PE 为负表示公司亏损，保留原值

## 5. 涨停股列表

### 用途

获取当日所有涨停个股，用于判定题材爆发力和个股核心度。

### 接口说明

- **来源**: 东方财富涨停股接口
- **请求方式**: HTTP GET
- **返回格式**: JSONP

### 关键返回字段

| 字段 | 含义 | 单位/说明 |
|:---|:---|:---|
| 股票代码 | 6位数字代码 | |
| 股票名称 | 个股中文简称 | |
| 最新价 | 涨停价格 | 元 |
| 涨跌幅 | 当日涨跌幅 | 百分比 |
| 连板天数 | 连续涨停天数 | 默认 1 |
| 涨停原因 | 涨停的题材/事件标签 | 字符串 |
| 封单金额 | 封板资金 | 元 |

### 涨停判定规则

- **普通股**: 涨跌幅 ≥ 9.8%
- **ST股**: 涨跌幅 ≥ 4.8%
- 当接口返回数据不足时，可从市场数据中补充筛选符合条件的个股

## 6. 市场情绪数据

### 用途

获取全市场涨跌统计，用于判断整体市场环境。

### 接口说明

- **来源**: 东方财富涨跌停统计接口 / 市场概览接口
- **请求方式**: HTTP GET
- **返回格式**: JSONP

### 关键返回字段

| 字段 | 含义 |
|:---|:---|
| 上涨家数 | 全市场上涨个股数量 |
| 下跌家数 | 全市场下跌个股数量 |
| 平盘家数 | 全市场平盘个股数量 |
| 涨停家数 | 全市场涨停个股数量 |
| 跌停家数 | 全市场跌停个股数量 |

### 市场情绪评级

| 条件 | 情绪评级 |
|:---|:---|
| 涨停数 ≥ 80 且 涨跌比 > 3 | **高潮** |
| 涨停数 ≥ 40 且 涨跌比 > 2 | **活跃** |
| 涨跌比 > 1 | **中性** |
| 涨跌比 > 0.5 | **低迷** |
| 其他 | **冰点** |

> 涨跌比 = 上涨家数 ÷ 下跌家数（下跌家数为0时，视为无穷大，评级为高潮）

---

## 通用约束

1. **请求频率**: 单次分析流程中，各接口按顺序调用，避免并发请求过多触发频率限制
2. **超时处理**: 单个接口请求超时（默认 10 秒）时跳过该数据点，使用默认值填充
3. **数据时效**: 建议在交易日盘中（9:30-15:00）或收盘后运行，获取当日最新数据
4. **降级策略**: 主接口失败时，可尝试备用数据源（如 AKShare），但字段映射需适配
